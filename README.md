# ShadowFox Internship Project — Image Tagging (CIFAR-10)

## 📌 Overview
This project was completed as part of my **AI/ML Internship with ShadowFox**.  
The goal was to build an **Image Classification (Image Tagging) model** using **Convolutional Neural Networks (CNNs)** on the **CIFAR-10 dataset**.

---

## 🎯 Objectives
- Preprocess and explore the CIFAR-10 dataset
- Build and train a CNN model with TensorFlow/Keras
- Evaluate accuracy and visualize predictions
- Save and document results as proof of work
